# RAMS — Road Asset Management System

A road-asset / pavement-condition management app for **Ethiopian federal and city corridors**: inventory, PCI condition scoring, defect register, maintenance programme optimiser, work-order board, field inspection form, and reports.

Standalone export (Macaly platform glue removed) so it runs anywhere with Node + a browser.

## Run it

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

| Script | Purpose |
|--------|----------|
| `npm run dev` | Development server (port 3000) |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
| `npm test` | Vitest unit tests (if present) |

## Stack

- **TanStack Start** + **React 19** + **TanStack Router**
- **Tailwind CSS v4**
- **Zustand** (client state, persisted to `localStorage`)
- **Leaflet** / react-leaflet (network map)
- **Recharts** (condition charts)
- No database and no auth — all data lives in the browser, seeded from `src/lib/rams/seed.ts`

Use **Reset demo data** in the sidebar to restore the seed (storage key `rams-v3`).

## Domain features

| Area | What it does |
|------|----------------|
| **Inventory** | Corridors, sections, assets (bridges, culverts, signs, …) |
| **PCI engine** | Transparent 0–100 score from inspection rating + defects, with optional IRI, AADT and pavement age adjustments |
| **Defects** | Register with severity, geometry, GPS, status workflow |
| **Programme optimiser** | Ranks maintenance activities by priority, condition gap, urgency and benefit/cost; respects budget |
| **Work orders** | Lifecycle from draft → completed / cancelled |
| **Field** | Inspection form + optional defect capture + GPS |
| **Engineering advisor** | On-device rule engine (no external API key) — treatment, cost order-of-magnitude, next actions |
| **Reports** | Network KPI summary and condition distribution |

### Ethiopian context

- Seed network: Addis–Adama Expressway (A1), Ring Road, Bole / Africa Avenue, Gojjam & Jimma roads, and related sections
- Costs in **ETB**; fiscal year labels use **Ethiopian Calendar** (e.g. FY 2018 E.C.)
- Indicative treatment unit rates (ETB/km) for planning only

## Project layout

```
src/
  components/
    layout/     App shell & navigation
    rams/       Map, condition badges
    ui/         Button, Card, Dialog, …
  lib/rams/
    types.ts      Domain types
    seed.ts       Demo network
    store.ts      Zustand store + networkStats
    condition.ts  PCI / priority / treatment
    optimizer.ts  Budgeted ranking + unit rates
    advise.ts     Rule-based engineering advisor
    format.ts     ETB, km, dates, tone classes
  routes/         File-based TanStack Router pages
```

## Notes

- The engineering advisor is fully local (`buildEngineeringAdvice` in `advise.ts`). Wire a real LLM later if you want free-text narrative on top of the same inputs.
- Route tree is generated by the TanStack Router plugin on `dev` / `build` (`routeTree.gen.ts` is gitignored).
- Path alias: `@/*` → `./src/*` (see `tsconfig.json`).
